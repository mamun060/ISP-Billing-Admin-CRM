# ISP Billing CRM

A modern customer and billing management system for an ISP business.

## Project Overview
This project is designed to help internet service providers manage customer accounts, billing cycles, subscriptions, support requests, and operational workflows from a single platform.

## Main Goals
- Manage customer profiles and service connections
- Track internet packages, add-ons, and billing plans
- Handle monthly billing, invoices, and payment statuses
- Monitor service activation, suspension, and renewals
- Support customer communication and ticket management
- Provide a scalable backend and a modern frontend for business operations

## Technology Stack
- Frontend: Next.js
- Backend: Django
- Database: PostgreSQL / SQLite for local development
- Architecture: Full-stack monorepo with separate frontend and backend layers

## Project Structure
- client-layer-frontend/: Frontend application built with Next.js
- service-and-data-layer-backend/: Backend services and data layer built with Django

## Current Status
This repository is in the initial project setup phase, with the frontend and backend layers separated for development and future expansion.

## Future Scope
- Admin dashboard
- Customer self-service portal
- Billing automation
- Invoice generation and payment tracking
